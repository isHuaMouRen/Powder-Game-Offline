# Powder Game 本地版

> [!tip]
> 此项目由 `GPT6-Luna` 制作

## 运行

直接用现代浏览器打开 `index.html` 即可开始游玩。游戏模拟和游戏资源均从本地文件加载；核心玩法不需要网络

## 粒子数量

页面可切换标准版和扩展版。扩展版提供 60,000、90,000、110,000 和 120,000 粒子四个档位；120,000 是该游戏 400×300 可玩区域的网格容量上限。高粒子数量会增加设备负载。

## 范围

本地版本包含 Powder Game 的模拟脚本和启动所需图像资源。浏览 DAN-BALL 社区作品、投票、注册及在线提交等依赖官网服务器的功能不属于离线版本。
